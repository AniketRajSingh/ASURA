## 🚀 Quick Start

### Installation
```bash
# Clone the repository
git clone https://github.com/asura-ai/asura
cd asura

# Install via uv (recommended)
uv sync --all-extras
```

### Starting the System
```bash
# Launch the interactive Sovereign Core
./asura
```
